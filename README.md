# ZERO POINT: Последний рубеж

Небольшой 3D FPS-прототип на Rust + Bevy. Это стилизованная научно-фантастическая тренировочная симуляция: игрок использует вымышленные энергетические импульсы против летающих тренировочных дронов. Реального оружия и реалистичных инструкций нет.

## Уже реализовано
- 3D-арена, освещение, укрытия и терминал.
- Камера от первого лица.
- Передвижение WASD / стрелки.
- Поворот мышью (удерживай левую кнопку мыши или Alt).
- Энергетические импульсы: RMB или Space.
- Дроны преследуют игрока и снижают щит при близком контакте.
- Заряд импульсов, запас, перезарядка на R.
- Терминал активируется клавишей E рядом с ним.
- Победа после активации терминала и отключения всех дронов.
- Экранный HUD.
- Базовые сенсорные зоны: левая часть экрана для движения, правая для обзора, верхняя правая область для импульса.

## Запуск на компьютере
Установи Rust и системные зависимости Bevy, затем в папке проекта:

```bash
cargo run
```

Для более высокой производительности:

```bash
cargo run --release
```

## Android
Проект пока является исходным кодом прототипа, а не готовым APK. Для Android-сборки нужны Android SDK, NDK, JDK и настройка мобильной оболочки Bevy. Официальная инструкция Bevy описывает сборку Android через `cargo-ndk` и Gradle. После добавления Android runner/оболочки потребуется проверить сенсорное управление на реальном устройстве.

Полезная официальная документация:
- https://bevy.org/learn/quick-start/getting-started/
- https://github.com/bevyengine/bevy/tree/latest/examples/mobile

## Управление
| Действие | Клавиатура / мышь | Сенсорный экран |
|---|---|---|
| Движение | WASD / стрелки | Левая половина |
| Обзор | Удерживать ЛКМ и двигать мышь | Правая половина |
| Энергетический импульс | RMB или Space | Тап в верхней правой зоне |
| Перезарядка | R | Пока только клавиатура |
| Терминал | E | Пока только клавиатура |
